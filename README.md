# ShopEase – E-Commerce Web Application

ShopEase is a full-stack e-commerce web application developed using PHP and MySQL. It provides an online shopping experience with product browsing, cart management, customer accounts, checkout and order tracking.

## Features

### Customer Features
- User registration and login
- Browse products and view product details
- Add products to cart
- Update product quantities and remove items
- Checkout and place orders
- View order history and order status

### Admin Features
- Admin dashboard with statistics
- Add, edit and delete products
- Upload product images
- View and manage customer orders
- Update order status
- View registered customers

### Technical Features
- PHP backend
- MySQL database integration
- Product and order management APIs
- Session-based authentication
- Role-based access control
- Responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Installation and Setup

1. Install XAMPP.
2. Copy the ShopEase project folder into the `htdocs` directory.
3. Start Apache and MySQL from XAMPP Control Panel.
4. Open phpMyAdmin.
5. Create a database named `shopease_db`.
6. Import the database SQL file.
7. Update the database connection settings in `config/db.php` if required.
8. Open the application in your browser:

   `http://localhost/ShopEase/`
